# 🐰 Algomon – Game Website

A multi-page promotional website for *Algomon*, a fictional adventure game where
you explore a forest as a rabbit: gathering resources, building shelter,
surviving and customising your character.

Built for the Client-Side Programming module (Year 1, BSc (Hons) Computing & IT,
CCT College Dublin, 2024).

🔗 **Live demo:** https://YOUR-USERNAME.github.io/algomon-game-website/

## Pages
- **Home** – game overview, gameplay features, online play and platforms
- **About** – game description, feature list and gallery preview
- **Gallery** – responsive image grid
- **Sign In / Create Account** – form layouts for user accounts

## Features
- Consistent page structure across all pages (header, navigation, sections, footer)
- Single external stylesheet for a unified look
- Sticky navigation bar, with a full-width hero image on the homepage
- Responsive gallery built with CSS Grid (`auto-fill` / `minmax`) that adapts
  to screen size
- Navigation designed around familiar web conventions (Jakob's Law), with the
  logo linking back to the homepage

## JavaScript Interactivity
- **Mouseover / mouseout** – navigation links change colour on hover
- **Scroll** – adjusts the navigation bar position as the user scrolls
- **Click** – confirmation alerts on the Sign In and Download buttons

## Tech
HTML5 · CSS3 · JavaScript (DOM event listeners)

## Run Locally
Download or clone the repository and open `index.html` in your browser.
